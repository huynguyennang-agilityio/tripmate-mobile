# MF2 interface (decided by the lead session)

The public names and files the MF2 tests use. The test agent copies this
into `test/INTERFACE.md`; the code agent builds exactly these names.

## Pinned contract

- `CONTRACTS_VERSION` (repository root): one line, `contracts-v0.2.0`, the
  `tripmate-contracts` tag this repository pins.
- `contracts/` (repository root): a byte-for-byte copy of the pinned tag's
  `openapi.json` and `translations/{en,vi}/*.json`. It is generated, never
  edited by hand. `contracts/openapi.json` is also a Flutter asset (listed in
  `pubspec.yaml`), read at runtime by the mock interceptor.

## Generated files

- `packages/tripmate_api/`: the `dart-dio` client generated by OpenAPI
  Generator from `contracts/openapi.json`; Dart package name `tripmate_api`,
  a path dependency of the app.
- `lib/l10n/app_en.arb` (template) and `lib/l10n/app_vi.arb`: generated from
  `contracts/translations/<lang>/*.json`. A key `area.snake_name` becomes the
  ARB key `areaSnakeName` (lowerCamelCase of the parts split on `.` and `_`),
  e.g. `auth.not_signed_in` -> `authNotSignedIn`. Values are copied unchanged
  (ICU).
- `lib/l10n/app_localizations.dart` (and the per-language files) from
  `flutter gen-l10n`: class `AppLocalizations`, import
  `package:tripmate_mobile/l10n/app_localizations.dart`, with
  `AppLocalizations.localizationsDelegates` and
  `AppLocalizations.supportedLocales` (`en`, `vi`).

## The generate and check tool

`dart run tool/contracts.dart <command> [--root <dir>] [--source <dir>]`

- `generate`: writes `contracts/`, the client, the ARB files, and the
  localizations from the pinned tag.
- `check`: regenerates everything into a temporary place and compares it with
  the files in the repository. Exit code 0 when everything matches; non-zero
  otherwise, printing the path of every file that differs, is missing, or is
  extra.
- `--root <dir>`: the repository to generate or check (default: the current
  directory).
- `--source <dir>`: a local directory laid out like `tripmate-contracts`
  (`openapi.json`, `translations/en/*.json`, `translations/vi/*.json`) used
  as the pinned tag instead of fetching `CONTRACTS_VERSION` from GitHub.
  Tests use it so they need no network.
- Generating the client needs Java 17 or later (`JAVA_HOME` or `java` on
  `PATH`); the tool downloads the pinned OpenAPI Generator jar and checks its
  SHA-256.

## Dart API (`lib/core/api/`)

- `lib/core/api/device_id.dart`
  - `class DeviceIdStore { DeviceIdStore({required SharedPreferences prefs}); String get deviceId; }`
    The first read makes a UUID v4 and saves it in `prefs`; every later read,
    also from a new `DeviceIdStore` over a new `SharedPreferences` instance
    after `SharedPreferences.resetStatic()` (an app restart in a test),
    returns the same value.
  - `class DeviceIdInterceptor extends Interceptor { DeviceIdInterceptor(DeviceIdStore store); }`
    sets the header `X-Device-Id` on every request.
- `lib/core/api/idempotency.dart`
  - `class IdempotencyKeyInterceptor extends Interceptor { IdempotencyKeyInterceptor(); }`
    On a `POST` (a create) that has no `Idempotency-Key` header, it writes a
    new UUID v4 into `options.headers['Idempotency-Key']`. A retry of the same
    action sends the same `RequestOptions` again (`dio.fetch(requestOptions)`,
    for example `error.requestOptions` after a failed attempt) and so carries
    the same key.
- `lib/core/api/mock_api.dart`
  - `class MockApiInterceptor extends Interceptor { MockApiInterceptor(Map<String, dynamic> contract); static Future<MockApiInterceptor> fromAsset(); }`
    `contract` is a parsed OpenAPI document; `fromAsset()` reads
    `contracts/openapi.json` from the asset bundle. For a request it finds the
    operation by method and path (path templates such as `/v1/trips/{id}`
    match), and answers with the example of its lowest 2xx response with
    `application/json` content: the media type's `example`, else the first
    value of its `examples`, else the schema's `example`, else the first item
    of the schema's `examples` (a `$ref` schema is followed). The response has
    that status code and the example as its data.
  - When the operation has no example, it rejects the request with a
    `DioException` whose `error` is a `MissingExampleError` and whose
    `message` contains the operation's `operationId`; no response data.
  - `class MissingExampleError implements Exception { final String operationId; }`
- `lib/core/api/api_client.dart`
  - `Dio createDio({required AppFlavor flavor, required ApiMode mode, required DeviceIdStore deviceIds, MockApiInterceptor? mock})`:
    base URL of the flavor; `DeviceIdInterceptor` and
    `IdempotencyKeyInterceptor` always; `mock` (required when `mode` is
    `ApiMode.mock`) last.

## App and the test screen

- `TripMateApp({required AppFlavor flavor, ApiMode apiMode = <ApiMode.current>, String initialLocation = '/', Locale? locale})`.
  `TripMateApp(flavor: ...)` alone keeps working (MF1 tests). Widget tests
  turn the mock on with `apiMode: ApiMode.mock` and call
  `SharedPreferences.setMockInitialValues({})` first.
- `lib/features/health/ui/health_screen.dart`: `class HealthScreen` with
  `static const String path = '/health'`. It reads `GET /v1/health` through
  the generated client and shows the answer's `status` and `version` values
  as text (each value as its own text, no other words around them).
- The app supports the locales `en` and `vi` through `AppLocalizations`.
